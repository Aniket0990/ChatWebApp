# 💬 MERN Real-Time Chat Application

A full-stack **real-time chat application** built using the **MERN stack (MongoDB, Express, React, Node.js)**.  
This application allows users to register, log in, send messages, share PDF files, view online/offline status, and see message delivery indicators.

The project demonstrates **full-stack development, REST API creation, authentication, database integration, and file sharing functionality.**

---

# 🚀 Features

- User Authentication (Register / Login)
- Real-time messaging
- Online / Offline user status
- Message delivery status
- Message Delete, Edit, Reply, Pin Messages
- Single tick ✔ – Message Sent
- Double tick ✔✔ – Message Delivered
- File sharing (PDF upload & download)
- Profile management (update name, email, profile photo, password)
- Secure API using JWT authentication
- Responsive chat interface

# 📤 File Sharing

Users can upload and share **PDF files** in chat.  
Files are stored securely using **Cloudinary** and shared through generated URLs.

---

# 👤 Profile Management

Users can update their profile information including:

- Name
- Email
- Profile Picture
- Password

The information is stored in **MongoDB** and displayed in the chat interface.

---

# 📡 Message Status

Message delivery status is displayed using tick indicators.

| Symbol | Meaning |
|-----  -|------|
| ✔      | Message Sent |
| ✔✔    | Message Delivered |
